# خطة ترحيل مركز ملفات الشركة إلى V2

## قاعدة الأمان

يبقى المسار الحالي لمركز ملفات الشركة هو الافتراضي. ميزة
`company_workspace_v2` تكون مغلقة افتراضياً، ولا تُفتح إلا لقائمة تجربة
محددة من حسابات موثوقة. لا يوجد في التطبيق أي موظف أو كود ثابت له صلاحية
تشغيل V2.

## مراحل الترحيل

1. إثبات العقود والاختبارات مع بقاء واجهة V1 كما هي.
2. تشغيل V2 لمستخدم تجريبي واحد أو مجموعة محددة بعد اكتمال اختبارات الصلاحية
   والتدقيق.
3. مقارنة الموارد والصلاحيات وسجل النشاط بين V1 وV2، ثم إصلاح أي فرق قبل
   توسيع المجموعة.
4. اعتماد المالك كتابةً لتحويل V2 إلى المسار الافتراضي بعد أدلة قبول كاملة.
5. يبقى V1 متاحاً كخيار رجوع حتى يحصل قرار منفصل لمراجعته وإزالته.

## الرجوع الفوري

عند ظهور فشل في تصفح ملف، حفظ تعديل، صلاحية، أو تقرير:

1. أوقف `company_workspace_v2` من مصدر الإعداد الموثوق.
2. افتح V1 للمستخدمين فوراً؛ لا تحذف الموارد أو بيانات العمليات المعلقة.
3. راجع سجل العمليات وسجل التدقيق التشخيصي الخاص.
4. أعد V2 فقط بعد اختبار عملية جديدة بنجاح والتحقق من عدم تكرار العملية.

لا يتطلب الرجوع تعديل قواعد Firestore أو حذف/إعادة تنظيم ملفات Google Drive.

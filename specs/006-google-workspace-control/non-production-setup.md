# إعداد بيئة غير إنتاجية لمركز الملفات

هذه القائمة مطلوبة قبل أي تجربة V2 مع بيانات شركة حقيقية.

- [ ] استخدم مجلد Google Drive تجريبي منفصل؛ لا تنقل أو تعِد تسمية ملفات الإنتاج.
- [ ] شارك المجلد التجريبي مع حساب الخدمة بصلاحية Editor فقط عند الحاجة.
- [ ] اضبط وجهة تقارير تجريبية مستقلة عن مجلد تقارير HR الفعلي.
- [ ] فعّل `company_workspace_v2` لمستخدم تجربة واحد فقط.
- [ ] تأكد أن الموظف التجريبي لا يملك رابط Google مباشر للملف نفسه إذا كانت تجربة الحوكمة مطلوبة.
- [ ] نفذ إنشاء ملف، رفع، تنزيل، تعديل Sheet، صلاحية، وتقرير ثم راجع سجل التدقيق.
- [ ] أوقف المفتاح وتحقق من أن المسار القديم ما زال يعمل قبل توسيع التجربة.

لا تضف مفاتيح خدمة أو كلمات مرور إلى التطبيق أو المستودع أو سجلات الاختبار.
